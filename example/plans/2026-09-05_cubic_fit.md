## 4. 驗證計畫

這組是合成資料，**真值已知**，所以可以做 [`../../tutorial/04_verification.md`](../../tutorial/04_verification.md)
裡最有效的那一項 ——「已知解對照」：

```
真值：force_N = 2.0·x³ − 5.0·x² + 3.0·x + 7.0
噪音：Gaussian, sigma = 2.0 N
```

- [ ] 三次項係數 a 與 2.0 誤差 < 5%
- [ ] 二次項係數 b 與 −5.0 誤差 < 5%
- [ ] 殘差標準差接近 2.0 N（±30% 內即可，樣本只有 80 筆）
- [ ] 殘差對 x 沒有系統性趨勢（畫殘差圖目視確認）
- [ ] 單位：圖與表的軸標與欄名都要有 mm / N

> 一次項 c 與常數項 d 的誤差通常較大，這是正常的 —— 在這個 x 範圍內
> 三次項主導，低次項對殘差的影響小，本來就較難估準。不用勉強讓它們也 < 5%。

## 5. 不確定與風險

- 若係數誤差遠大於 5%，先檢查是不是檔頭沒跳過（把 `#` 那幾行當成數字讀進去）
- 若圖是空白的，先檢查有沒有存檔前就 `plt.show()`
