# 4. 物理合理性檢查

`instructions.md` 第六節列了六項檢查。這裡說明每一項實際要看什麼，以及怎麼分辨「真的檢查了」和「說有檢查」。

## 通則

要求 agent 附上**支持結論的數字**，不是結論本身。

- 沒用：「單位已確認一致 ✓」
- 有用：「acc_x 原始 min/max = −3.2/3.4 g，乘 9.80665 後 −31.4/33.3 m/s²，與 SPEC 的 ±50 g 量程相符」

第二種你可以自己驗算，第一種你只能相信它。

---

## 六項檢查

### 1. 單位

最常出事的一項。要看的是**每一次換算發生在哪一行**。

常見陷阱：g ↔ m/s²（差 9.80665）、mm ↔ m（差 1000）、Hz ↔ rad/s（差 2π）、mV ↔ N（看校正係數）。

問法：「列出從原始 CSV 到最終結果，每個物理量經過的單位換算，對照 `SPEC.md` 第一節。」

### 2. 數量級

不用精算，看指數對不對。

| 量 | 合理範圍 |
|---|---|
| 鋼材應力 | 10⁶–10⁸ Pa |
| 楊氏模數（鋼） | ~2×10¹¹ Pa |
| 實驗室結構一階頻率 | 1–10² Hz |
| 應變 | 10⁻⁶–10⁻³ |

差 10³ 通常是 mm/m，差 ~10 通常是 g，差 2π 通常是 Hz/rad·s⁻¹。

### 3. 守恆量

有理論保證就一定要查，因為它會抓到你想不到的錯：

- **Parseval**：FFT 前後總能量應相等，誤差 < 1%
- 濾波前後能量差 = 被濾掉的頻段能量，若差太多代表濾掉了真訊號
- 質量、動量在模擬前後守恆

### 4. 邊界與初始條件

跟 `SPEC.md` 對一遍。座標系原點、重力方向、固定端在哪、初始位移速度。

模擬結果「看起來怪」，八成是這裡跟你想的不一樣。

### 5. 極端情況

最便宜、最有效的一項。把參數推到極端，看結果符不符合物理直覺：

| 設定 | 應該發生什麼 |
|---|---|
| 阻尼 = 0 | 自由振動不衰減，振幅維持定值 |
| 外力 = 0 | 系統停在初始狀態 |
| 剛度 → ∞ | 位移 → 0，頻率 → ∞ |
| 質量 → ∞ | 頻率 → 0 |

任何一項不對，程式就是有 bug —— 這比對著實驗數據瞎猜快得多。

### 6. 已知解對照

有解析解或教科書案例就一定要比。懸臂樑、單自由度系統、簡支樑都有閉合解。

在已知案例上誤差 < 1%，你才有理由相信它在你的真實資料上是對的。

---

## 檢查不過怎麼辦

`instructions.md` 寫得很明白：**若任何一項無法通過或無法檢查，明確說出來，不要略過。**

「無法檢查」也是合法答案 —— 沒有解析解可比就說沒有。不合法的是安靜跳過。

發現 agent 略過檢查，或給了無法驗算的空話，把那一項退回去重做。放過一次，之後每次都會被略過。
