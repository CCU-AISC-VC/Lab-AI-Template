# 教學：用 AI agent 做研究分析

這套教學教你把 AI coding agent 從「會寫程式的聊天機器人」變成「可信任的研究助理」。

預計時間：第一次讀完約 30 分鐘，實際跑完第一個任務約 1–2 小時。

## 三份核心檔案

整套流程靠這三份檔案運作，其他都是輔助：

| 檔案 | 回答什麼問題 | 誰維護 |
|---|---|---|
| `instructions.md` | Agent 該怎麼工作？什麼不准做？ | 一次寫好，很少改 |
| `SPEC.md` | 這個專案的物理世界長什麼樣？ | 實驗設定一變就改 |
| `DEVLOG.md` | 過去做了什麼、為什麼？ | 每個任務結束補一筆 |

**最重要的一句話**：agent 看不到你的實驗室。單位、座標系、感測器怎麼裝的，你不寫在 `SPEC.md`，它就會用「最常見的猜測」補上去，然後給你一個看起來很合理的錯答案。
